# User Authentication API

A Node.js, Express.js and MongoDB based User Authentication API using JWT.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Postman

## API Endpoints

### 1. Register User

**Method:** POST

**Endpoint:** `/api/auth/register`

**Request Body:**

```json
{
  "username": "sajina",
  "email": "sajina@example.com",
  "password": "Password@123"
}
```
